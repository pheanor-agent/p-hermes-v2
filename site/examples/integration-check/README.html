합성 fixture · 로컬 전용

integration-check

요청에서 작업 흐름·지식 참조·가짜 이미지 실행·검증·응답까지 연결합니다.

전체 흐름 속 위치

이 예제는 실제 서비스를 부르지 않고 각 연결 계약을 한 번에 확인합니다.

  1. 요청 ID와 완료조건을 읽습니다.
  2. 단계 계약을 확인합니다.
  3. 합성 context pack의 출처 상태를 확인합니다.
  4. fake runtime이 표식 파일을 만듭니다.
  5. 조건·파일·응답 상태를 대조합니다.

시작

make test
make example NAME=integration-check

기대 결과

정상 입력은 같은 요청 식별자의 done 응답을 만듭니다. 조건 누락 또는 출처 미확인 입력은 partial로 표시합니다. 앞서 만든 산출물은 남습니다.

파일 구조

  • AGENTS.md: 안전 경계
  • PROMPT.md: 에이전트 과제
  • fixtures/: 합성 입력과 조건 충족/미충족 사례
  • src/: 통합 점검기와 CLI 진입점
  • tests/: 응답 일치와 산출물 보존 확인

Python 표준 라이브러리만 사용합니다. GPU·네트워크·외부 서비스·자격 증명은 필요하지 않습니다. 실제 이미지 생성이나 게시를 수행하지 않습니다.
