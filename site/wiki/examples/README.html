예제 카탈로그

지휘 에이전트와 작업 에이전트의 흐름을 이해하고 확인하기 위한 문서입니다.

예제 카탈로그

전체 흐름 속 위치

지휘 에이전트(매니저)가 과제의 경계를 정하고, 작업 에이전트(워커)가 예제를 수행하며, 테스트가 결과를 확인합니다.

예제 학습 목표 수행 명령 상태
portable-worker 요청·응답 계약, 안전한 입력 범위, terminal 상태 make example NAME=portable-worker 제공
knowledge-context-check 검색 후보·원문·출처 상태 구분, 빈 결과 기록 make example NAME=knowledge-context-check 제공
integration-check 요청 → 단계 계약 → 맥락 → light JOB 게이트 파일·승인 근거 → 응답 make example NAME=integration-check 제공

예제는 p-hermes 자체 동작에 한정하며 도메인 비유를 사용하지 않습니다. 세 예제 모두 합성 입력만 쓰며 Python 3.11 표준 라이브러리로 실행됩니다.
