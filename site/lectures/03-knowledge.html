지식 참조는 작업 흐름의 어디에서 무엇을 돕나요?

결과에서 교훈을 기록할 수 있지만, 기록이 다음 작업에서 쓰인다는 보장은 없습니다.

작업의 교훈은 다시 찾을 수 있도록 기록됩니다

작업 결과에서 배운 내용은 기록 지점으로 돌아갈 수 있습니다. 하지만 저장은 검색이나 실제 사용과 다른 단계이므로, 기록만으로 다음 작업에 활용됐다고 볼 수는 없습니다.

03 / 09

자료를 저장하는 일과 질문에 맞는 자료를 검색하는 일은 분리됩니다.

저장과 검색은 별개이며, 검색은 자료를 놓칠 수 있습니다

질문을 입력해 후보 자료를 찾지만, 실제 검색이 단어 일치 중심이면 의미상 맞는 자료를 놓칠 수 있습니다. 후보가 적거나 비어 있다는 사실도 숨기지 않고 남겨야 합니다.

관련 후보의 정확성과, 필요한 자료를 찾는 범위를 함께 살핍니다.

관련성과 빈 결과를 함께 보아야 합니다

검색 결과의 정밀도는 나온 후보가 얼마나 관련 있는지 살핍니다. 커버리지는 요청에 답할 자료를 어느 범위까지 찾았는지 봅니다. 한쪽만으로 검색 품질 전체를 판단할 수 없습니다.

요청에 대한 근거가 없다는 결과도 후보의 관련성과 별도로 기록합니다.

05 / 09

자동 제공은 자료를 보여주는 경로이며, 원문 판단을 대신하지 않습니다.

자동 제공은 참고 경로이지 정답 보증이 아닙니다

검색으로 찾은 자료는 원문과 현재 상태를 확인해야 합니다. 자동으로 보여 주었다는 사실만으로 내용이 맞거나 실제 판단에 사용됐다고 볼 수 없습니다.

전체 흐름 · 확인하지 못한 값

06 / 09

정보가 확인되지 않은 상태는 미확인으로 그대로 둡니다.

출처나 날짜를 알 수 없으면 unknown으로 둡니다

확인 가능한 출처와 시점은 기록하고, 확인할 수 없는 값은 `unknown`으로 남깁니다. 날짜가 없다는 이유로 최신이라고 추정하거나 오래됐다는 표시만으로 내용이 틀렸다고 판단하지 않습니다.

표시된 상태는 확인 수준을 나타내며, 정보의 참·거짓을 자동 판정하지 않습니다.

07 / 09

후보가 정본이나 재사용 절차가 되는 결정은 검토와 구분됩니다.

자동 수집과 사람의 검토·승격은 다른 일입니다

자료를 수집하고 후보로 표시하는 자동화는 검토를 끝내지 않습니다. 사람의 근거 확인과 결정이 있기 전에는 후보를 정본이나 재사용 절차로 승격하지 않습니다.

전체 흐름 · 확인 경로만 연결

08 / 09

검증된 원문 확인 경로만 작업의 판단 근거로 연결합니다.

출처와 상태를 확인한 자료만 판단 근거로 연결합니다

검색 후보, 원문 확인, 출처 상태, 사람의 검토는 구분된 절차입니다. 원문을 확인하지 못했거나 검토 대기 중인 후보는 작업에 쓰인 근거와 분리해 둡니다.

후보를 근거로 바꾸는 것은 자동 표시가 아니라 확인 절차입니다.

결과의 교훈은 기록·검토 경로로 돌아와, 확인된 근거가 다음 작업을 돕습니다.

확인된 지식은 작업을 돕고, 새 교훈은 기록으로 돌아갑니다

작업 흐름의 필요한 지점에 확인된 근거를 제공하고, 결과와 새 교훈은 기록과 검토 경로로 돌아갑니다. 이 순환이 전체 동작 흐름 안에서 지식 참조가 놓이는 자리입니다.
