# 시스템을 이해하는 다섯 가지 관점

> 로컬 대표 시안. 전체 문서·강의는 아직 완성되지 않았습니다.

[전체 관계도와 읽는 방법](overview.md) · [강의 보기](lectures/index.html)

| 분야 | 먼저 답할 질문 | 기술로 내려가면 |
|---|---|---|
| 작업 | 맡긴 일을 어떻게 안전하게 끝낼까? | 승인 경계, 상태 전이, 충돌 검증, 실패 복구 |
| 지식 | 정보를 어떻게 다시 쓸 수 있게 만들까? | 출처, 메타데이터, 등록, 인덱스, 검색 |
| 카탈로그 | 무엇을 어떤 버전으로 사용할까? | 자산 계약, 버전 고정, 파라미터 바인딩 |
| 영상 | 장면을 어떻게 시간 안에서 연결할까? | 샷 계약, 참조, 타임라인, 후보 검증 |
| 이미지 | 시각적 의도를 어떻게 전달할까? | 구도, 프롬프트, 생성 입력, 품질 검토 |

읽는 순서는 **개념 → 구조 → 동작 → 기술 구현 → 검증**입니다. 앞의 계층은 목적과 관계를 설명하고, 뒤의 계층은 실제 근거와 제약을 설명합니다.
