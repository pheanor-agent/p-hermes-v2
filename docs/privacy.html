Hermes 개인정보처리방침

시행일: 2026-11-13

Hermes는 운영자 한 사람이 자기 컴퓨터에서 쓰는 개인 자동화 도구입니다. 일반 사용자에게 제공하는 서비스가 아닙니다.

사용하는 Google 데이터

Hermes는 Gmail API로 운영자 본인 계정의 메일을 검색하고 읽고, 운영자가 지시한 메일을 보냅니다. 다른 사람의 계정에는 접근하지 않습니다.

저장과 공유

  • OAuth 토큰과 메일 처리 결과는 운영자의 로컬 컴퓨터에만 보관합니다.
  • Google 사용자 데이터를 판매하거나 제3자에게 넘기지 않으며, 광고에 쓰지 않습니다.
  • Hermes가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

권한 철회

Google 계정의 서드파티 연결 관리에서 언제든 Hermes의 접근 권한을 철회할 수 있습니다.

Hermes Privacy Policy

Effective: 2026-11-13

Hermes is a personal automation tool run by a single operator on their own machine. It is not offered to the public.

Hermes uses the Gmail API to search, read, and send email only in the operator's own account. OAuth tokens and results are stored only on the operator's local machine. Google user data is never sold, shared with third parties, or used for advertising.

Hermes's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time at Google Account → Third-party connections. Contact: pheanor.agent@gmail.com
