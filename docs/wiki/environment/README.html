저장소 환경 안내

지휘 에이전트와 작업 에이전트의 흐름을 이해하고 확인하기 위한 문서입니다.

저장소 환경 안내

전체 흐름 속 위치

지휘 에이전트(오케스트레이터)가 정한 범위에 따라 작업 에이전트(워커)가 환경을 확인하고 과제를 수행합니다.

확인일: 2026-09-29. 아래 제품 동작은 공식 문서 링크에서 확인한 범위만 적었습니다. 운영체제별 상세 설치 명령은 제품의 최신 설치 페이지를 따르세요.

OS와 Python

Linux·macOS·Windows에서 저장소를 내려받고 터미널을 엽니다. Python 3.11 이상이 필요합니다. 확인: python3 --version 또는 Windows에서 py --version. make test는 Python 표준 라이브러리만 사용합니다.

가상환경(선택)

python3 -m venv .venv
. .venv/bin/activate

Windows PowerShell: py -m venv .venv 후 .venv\Scripts\Activate.ps1. 이 실습은 외부 패키지가 없어 가상환경을 선택적으로 사용할 수 있습니다.

Claude Code

Claude Code는 프로젝트 지침으로 CLAUDE.md를 지원합니다. 이 저장소의 파일은 공통 규칙 AGENTS.md를 읽도록 안내합니다. 프로젝트 루트에서 Claude Code를 시작하고 examples/portable-worker/PROMPT.md의 과제를 전달하세요. 공식 안내: https://docs.anthropic.com/en/docs/claude-code/memory

Codex

Codex는 저장소 지침으로 AGENTS.md를 읽습니다. 저장소 루트에서 Codex를 열고 같은 PROMPT.md 과제를 전달하세요. 공식 안내: https://developers.openai.com/codex/agent-configuration/agents-md

범용 에이전트

어떤 도구든 먼저 AGENTS.md와 예제 README.md를 제공하고, PROMPT.md의 과제를 입력합니다. 제품별 자동 연동을 가정하지 말고 테스트 명령을 작업 에이전트가 직접 수행하도록 요청하세요.

문제 해결: 증상 → 원인 → 확인 → 조치

  • python3를 찾지 못함 → Python 미설치 또는 PATH 문제 → python3 --version, Windows는 py --version → Python 3.11 이상을 설치하고 새 터미널에서 재확인.
  • make 명령이 없음 → make 미설치/Windows 기본 셸 → Python 테스트 명령을 직접 수행: python3 -m unittest discover -s examples/portable-worker/tests -v.
  • 테스트 import 실패 → 저장소 루트가 아닌 위치에서 명령을 수행했을 가능성 → pwd로 위치 확인 → 저장소 루트로 이동 후 make test.
  • 권한 오류 → 가상환경 활성화/파일 권한 확인 → 저장소 안에서만 작업하고 관리자 권한으로 우회하지 않음.
