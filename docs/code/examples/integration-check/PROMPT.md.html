# 에이전트 과제

`fixtures/pass/`의 합성 요청·단계 계약·맥락·JOB 파일 목록을 읽고 통합 점검기를 실행하세요.

완료 조건:
1. 응답의 요청 식별자가 입력과 같습니다.
2. 모든 조건, 계약, 출처, light JOB 필수 파일과 승인 근거를 확인한 경우에만 `done`입니다.
3. 산출물은 검증 전에 남기고, 검증이 실패해도 지우지 않습니다.
4. 조건 누락·미확인 출처·누락 파일 사례는 `partial`이며 누락 항목을 응답에 적습니다.
5. `make example NAME=integration-check` 결과를 보고합니다.

실제 사용자 경로·키·외부 서비스·GPU에 접근하지 마세요.
