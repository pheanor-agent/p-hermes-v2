# 에이전트 과제

`fixtures/pass/`의 합성 요청·단계 계약·맥락·카탈로그를 읽고 통합 점검기를 실행하세요.

완료 조건:
1. 응답의 요청 식별자가 입력과 같습니다.
2. 모든 조건, 계약, 출처를 확인한 경우에만 `done`입니다.
3. fake runtime은 합성 표식 파일만 만듭니다.
4. 조건 누락·미확인 출처 사례는 비완료이며, 먼저 만들어진 산출물은 보존합니다.
5. `make example NAME=integration-check` 결과를 보고합니다.

실제 사용자 경로·키·외부 서비스·GPU에 접근하지 마세요.
