합성 요청을 통합 점검하세요

현재 fixture만 사용해 연결 계약과 결과를 스스로 확인합니다.

  1. fixtures/pass/에서 합성 요청·단계 계약·context pack·카탈로그를 읽습니다.
  2. 정상 실행이 요청 식별자를 그대로 반환하고 done인지 확인합니다.
  3. fixtures/missing/에서 조건 누락과 출처 미확인을 점검합니다.
  4. 미완료 응답과 함께 fake 산출물 표식 파일이 보존되는지 확인합니다.
  5. 저장소 루트에서 make test와 make example NAME=integration-check을 실행합니다.

외부 서비스·GPU·실제 사용자 파일·자격 증명에 접근하지 않습니다. 입력 fixture를 수정하지 않습니다. 테스트 결과를 사실대로 보고합니다.
