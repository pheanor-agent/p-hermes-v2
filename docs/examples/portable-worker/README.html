지휘 에이전트와 작업 에이전트의 흐름을 이해하고 확인하기 위한 문서입니다.

portable-worker: 파일 handoff 최소 실습

전체 흐름 속 위치

지휘 에이전트(오케스트레이터)가 요청을 만들고, 작업 에이전트(워커)가 격리된 입력을 처리해 응답을 남기며 테스트가 확인합니다.

목적은 합성 요청을 검증하고 허용된 입력 아래에서 terminal 응답을 만드는 흐름을 직접 확인하는 것입니다.

한 줄 명령(저장소 루트): make example NAME=portable-worker

기대 결과: 계약 테스트가 모두 통과합니다. 테스트는 임시 폴더에서 정상·차단·실패·부분 성공 상태, 요청 ID와 응답 연결, 산출물 보존을 검사합니다. 실제 서비스 호출은 없습니다.

자기 검증: make test가 0 종료 코드인지 확인합니다. 세부 모듈은 src/, 합성 입력은 fixtures/, 검증은 tests/에 있습니다.
