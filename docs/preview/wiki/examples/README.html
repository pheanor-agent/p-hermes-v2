예제 카탈로그

지휘 에이전트와 작업 에이전트의 흐름을 이해하고 확인하기 위한 문서입니다.

예제 카탈로그

전체 흐름 속 위치

지휘 에이전트(오케스트레이터)가 과제의 경계를 정하고, 작업 에이전트(워커)가 예제를 수행하며, 테스트가 결과를 확인합니다.

예제 학습 목표 수행 명령 상태
portable-worker 요청·응답 계약, 안전한 입력 범위, terminal 상태 make example NAME=portable-worker 제공
workflow-guard 허용/차단 상태 전이 미정 예정
image-catalog-fake-runtime 카탈로그·프롬프트·런타임 분리 미정 예정
knowledge-provenance 실제 시스템 자료 흐름 미정; 실물 복구 후에만 작성 게이트 대기

예제는 p-hermes 자체 동작에 한정하며 도메인 비유를 사용하지 않습니다. 목록의 예정 항목은 구현된 기능이 아닙니다.
