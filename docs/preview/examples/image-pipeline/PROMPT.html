에이전트 과제: 프롬프트 계약을 보강하세요

저장소 루트의 README와 이 예제의 README.md, PROMPT.md를 먼저 읽으세요. 그런 다음 합성 fixture만 사용해 constraints 필드가 빈 경우와 채워진 경우 모두 동작하는 테스트를 하나 추가하세요.

제약:

  • fixtures/ 입력은 과제 수행 중 수정하지 않습니다.
  • 실제 사용자 이미지·경로·자격증명을 사용하지 않습니다.
  • 네트워크, GPU, 외부 서비스에 연결하지 않습니다.
  • 요청의 주제와 행동은 보존하고, 범위 밖 코드는 수정하지 않습니다.

완료조건:

  1. 추가한 테스트가 검증하는 계약을 한국어로 설명합니다.
  2. make test를 실행하고 실제 결과를 기록합니다.
  3. 변경 파일과 남은 제한을 보고합니다.
  4. 실제 이미지 생성이 수행된 것처럼 표현하지 않습니다.
