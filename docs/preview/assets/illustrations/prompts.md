# 일러스트 프롬프트·제작 기록

## 공통 시각 방향

한국어 입문 강의용 편집 일러스트. 짙은 남색 배경, 민트·하늘색·호박색 포인트, 단순한 도형과 넉넉한 여백. 이미지 안에는 글자를 넣지 않고 설명은 HTML로 제공한다.

## ChatGPT 이미지 생성 시도

요청한 공통 프롬프트: “Create one polished editorial illustration, landscape 3:2, for a Korean educational slide deck about AI agents. Show a friendly human handing a glowing blank request card to two distinct collaborating abstract AI agents, one planning and one executing, with a clear path leading to a checked result. Deep navy background, teal and warm amber accents, refined flat vector meets soft 3D, high contrast, generous negative space, no lettering, no symbols resembling text, no logos.”

ChatGPT CDP는 인증된 입력 화면까지 확인했으나, 생성 요청 후 제한 시간 내 안정된 응답 또는 이미지 파일을 회수하지 못했다. 따라서 이 자료는 ChatGPT 생성 이미지가 아니다.

## SVG 대체안

ChatGPT 산출물을 얻지 못해 요청서의 SVG 대체 경로를 사용했다. 아래 3개는 동일 팔레트·도형 스타일의 수제 벡터이며, 글자는 HTML 제목/설명으로 제공한다.

- `context.svg`: 대화 맥락이 흩어지고 요청 카드가 남는 장면
- `handoff.svg`: 지휘 에이전트와 작업 에이전트가 파일을 주고받는 장면
- `verification.svg`: 완료 보고를 실제 결과와 대조하는 장면

모든 그림은 합성 도형으로 제작했으며 외부 자산·네트워크 요청이 없다.
