p-hermes 재정비 파일럿 미리보기(리뷰용)

요청에서 허용된 상위 에이전트·워커 파일럿 자료만 모았습니다. 기존 사이트 콘텐츠는 이 경로에서 대체하지 않습니다.

강의 00 · 전체 그림

Hermes가 필요한 이유와 네 축이 만나는 흐름을 먼저 살펴봅니다.

강의 01 · 상위 에이전트와 워커

요청을 맡기고 결과를 확인하는 역할과 책임을 살펴봅니다.

해설

파일 handoff가 시도 구분과 결과 확인에 주는 이점을 읽습니다.

위키

portable 교육 킷의 요청·응답 계약과 실패 경계를 찾아봅니다.

실습

합성 fixture로 worker와 검증 테스트를 실행하는 방법을 따라 합니다.

환경 대응표

Claude Code 사례, Codex 미검증 제안, generic Python 예시를 구분합니다.

코드

참조 모듈·예제·테스트를 읽고 개별 원본 파일을 내려받습니다.

코드로 확인하기

코드 페이지는 HTML escape를 적용한 보기 화면과 원본 다운로드 링크를 함께 제공합니다. 예제는 합성 입력이며 실서비스 연동은 하지 않습니다.
