p-hermes 재정비 파일럿 미리보기(리뷰용)

처음 방문하면 강의 00부터 순서대로 시작합니다. 이어지는 각 강의는 앞선 질문을 받아 전체 흐름을 완성합니다.

처음 시작하는 학습 경로 · 강의 00~05

  1. 강의 00 · 전체 흐름
  2. 강의 01 · 지휘·작업 에이전트
  3. 강의 02 · 작업 흐름
  4. 강의 03 · 지식 참조 (P4 통합 대기)
  5. 강의 04 · 이미지 생성
  6. 강의 05 · 통합

강의

  • 강의 00 · 전체 그림 — 에이전트 시스템의 전체 흐름과 결과 확인을 살펴봅니다.
  • 강의 01 · 지휘 에이전트와 작업 에이전트 — 계획·위임 역할과 맡은 작업을 수행하는 역할을 구분합니다.
  • 강의 02 · 작업 흐름 — 단계 계약과 검증을 전체 흐름 안에서 살펴봅니다.
  • 강의 04 · 이미지 생성 파이프라인 — 카탈로그·프롬프트·어댑터·검증의 흐름을 살펴봅니다.
  • 강의 05 · 통합 — 네 축을 요청부터 검증된 결과 보고까지 연결합니다.

해설

  • 왜 파일 handoff가 필요한가 — 요청과 결과를 파일로 주고받는 이유를 설명합니다.

위키

  • 환경 — 실습 저장소와 실행 환경의 전제 조건을 확인합니다.
  • 예제 안내 — portable worker 예제의 구성과 사용 경로를 살펴봅니다.
  • 계약 — 요청·응답 필드와 상태 전이를 찾아봅니다.
  • 작업 흐름 참조 — 현재 단계 계약, 검사, 활성 범위를 찾아봅니다.
  • 용어 — 문서에서 사용하는 핵심 용어를 확인합니다.
  • 이미지 생성 파이프라인 참조 — 예제의 공개 계약과 확인 절차를 찾아봅니다.
  • 통합 연결 계약 — 요청·단계·지식·산출·검증의 연결 계약을 찾아봅니다.

예제

  • portable worker 실행 — 합성 fixture로 portable worker를 실행합니다.
  • 작업 프롬프트 — 예제에 사용할 안전한 작업 지시를 확인합니다.
  • 이미지 파이프라인 예제 — 합성 입력으로 오프라인 파이프라인을 재현합니다.
  • 이미지 파이프라인 과제 — 에이전트에게 맡길 안전한 테스트 과제를 확인합니다.
  • 통합 예제 — 합성 입력으로 전체 연결을 오프라인에서 확인합니다.
  • 통합 예제 과제 — 에이전트가 안전한 통합 계약을 점검합니다.

예제 코드

  • 예제 코드·소스와 테스트 — 예제 구현과 테스트를 읽고 원본 파일을 내려받습니다.

예제 코드는 HTML escape를 적용한 보기 화면과 원본 다운로드 링크를 함께 제공합니다. 입력은 합성 fixture이며 실서비스 연동은 하지 않습니다.
