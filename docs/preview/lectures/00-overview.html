작업 에이전트가 맡은 범위를 처리합니다

작업 에이전트(워커)는 전달받은 목표와 경계 안에서 맡은 일을 수행하고 결과를 돌려줍니다.

왜 둘로 나눌까요? 판단 쪽은 실행 세부에 계속 맥락을 쓰지 않고 목표·경계를 지킵니다. 실행 결과는 다른 쪽이 독립적으로 확인해, 수행과 확인이 한 판단에 섞이지 않게 합니다.

작업 흐름의 각 단계는 목적에 맞는 원문과 근거를 찾아 사용할 수 있습니다. 지식은 전체 흐름 안에서 필요한 맥락을 제공하는 역할입니다.

이 장에서는 지식의 위치와 역할만 표시합니다. 세부 저장소나 복구 상태는 다루지 않습니다.
