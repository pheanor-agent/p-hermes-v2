# 작업 과제: 프롬프트 제약 보존 테스트

## 목표
`constraints` 값이 있으면 프롬프트 출력에 보존되고, 값이 없으면 선택 필드로 조용히 생략되는 계약을 확인하는 테스트를 추가하세요.

## 순서
1. 저장소 루트의 README와 `examples/image-pipeline/README.md`를 먼저 읽습니다.
2. `src/image_pipeline_demo/pipeline.py`와 기존 테스트를 읽습니다.
3. 합성 입력을 사용해 테스트를 추가합니다.
4. `make test`를 실행하고 결과를 보고합니다.

## 경계
fixture를 변경하지 않습니다. 네트워크·GPU·실제 홈 경로·실제 이미지·자격증명을 사용하지 않습니다. 실제 생성이나 게시를 수행했다고 주장하지 않습니다.

## 완료 조건
추가 테스트가 통과하고, 변경 파일·테스트 명령·남은 제한을 한국어로 요약합니다.
