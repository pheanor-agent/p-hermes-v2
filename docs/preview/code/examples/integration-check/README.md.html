# integration-check · 통합 흐름 점검

## 전체 흐름 속 위치
강의 00~05의 연결을 합성 입력 하나로 확인합니다. 지휘 에이전트가 보낸 요청을 작업 에이전트가 단계 계약과 확인된 맥락 안에서 처리하고, GPU 없는 가짜 이미지 실행 결과를 조건에 대조한 뒤 응답합니다.

```mermaid
flowchart LR
  A[요청] --> B[단계 계약]
  B --> C[확인된 맥락]
  C --> D[가짜 이미지 실행]
  D --> E[산출물 보존]
  E --> F[조건 검증]
  F --> G[응답]
```

## 시작
저장소 루트에서 실행합니다.

```sh
make example NAME=integration-check
```

전체 예제 검사는 `make test`입니다. Python 표준 라이브러리만 사용합니다.

## 기대 결과
정상 fixture는 요청 식별자를 유지하고 `done` 응답 및 합성 산출물 경로를 냅니다. 조건 누락 또는 출처 미확인은 완료로 오인하지 않습니다. 이미 만들어진 산출물은 검증이 실패해도 남습니다. 실제 이미지 생성·게시를 뜻하지 않습니다.

## 구성
- `AGENTS.md`: 에이전트 작업 경계
- `PROMPT.md`: 에이전트 과제 지시
- `fixtures/`: 합성 요청·단계 계약·맥락·카탈로그 및 오류 사례
- `src/`: 통합 점검기와 가짜 실행
- `tests/`: 완료·비완료·산출물 보존 확인

외부 서비스, 네트워크, GPU, 자격 증명은 사용하지 않습니다.
