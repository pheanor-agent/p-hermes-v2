# 에이전트 작업 안내

- `fixtures/`의 합성 입력만 사용하고 실제 사용자 파일을 읽지 않습니다.
- 외부 송신, 네트워크, GPU, 모델 호출, 자격 증명 접근은 금지합니다.
- 입력 fixture를 덮어쓰지 않습니다. 테스트 출력은 임시 디렉터리에 둡니다.
- 검증 실패를 성공으로 바꾸지 말고, 이미 만들어진 산출물은 보존합니다.
- 실행: 저장소 루트에서 `make example NAME=integration-check`; 전체 검사: `make test`.
