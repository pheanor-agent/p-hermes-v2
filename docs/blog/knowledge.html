지식 근거 — 최신 정보를 왜 그대로 믿지 않는가

자료를 많이 모으는 것보다 출처·적용 범위·상태를 확인해 현재 판단에 쓸 근거를 고르는 일이 왜 중요한지 설명합니다.

지식 근거는 판단 전체를 어떻게 지탱하는가

지식의 양보다 어떤 판단에 어떤 근거를 사용했는지 다시 확인할 수 있는지가 중요합니다.

작업은 자료가 부족해서 실패하기도 하지만, 현재 상황에 맞지 않는 자료를 믿어서 실패하기도 합니다. 우리는 자료를 모으는 것에서 끝내지 않고, 어디에서 왔고 어떤 범위에 적용할 수 있는지 확인한 뒤 현재 판단에 쓸 근거를 고릅니다. 이 선택이 이후 자원 선택과 제작 판단의 출발점이 됩니다.

전체 흐름은 자료를 발견하고, 출처와 범위를 확인하고, 현재 질문에 맞는 근거를 채택하고, 필요할 때 다시 찾아 쓰고, 더 이상 현재 판단에 쓰지 않을 때 제외하는 과정입니다. 검색은 그중 필요한 항목을 찾는 수단일 뿐입니다. 검색 결과가 많이 나온다고 해서 판단의 신뢰도가 자동으로 높아지지는 않습니다.

같은 제품의 색처럼 작은 사실도 같은 원리를 따릅니다. 과거 대화에서 본 색 이름보다 어느 버전의 제품을 설명한 자료인지, 언제 어떤 출처에서 확인했는지가 중요합니다. 뒤에서는 발견한 자료와 실제 근거를 왜 나누는지, 충돌한 정보를 어떻게 비교하는지, 오래된 근거를 어떻게 다루는지를 살펴봅니다.

자료와 근거를 왜 구분해야 하는가

발견한 자료는 후보이고, 출처와 적용 범위를 확인한 뒤에야 현재 판단의 근거가 됩니다.

대화에서 본 문장, 파일에서 찾은 내용, 검색으로 나온 항목은 모두 유용한 자료가 될 수 있습니다. 그러나 발견됐다는 사실만으로 지금 작업에 그대로 적용할 수 있는 것은 아닙니다. 우리는 원래 문맥과 출처, 대상과 시점을 확인해 현재 질문에 쓸 수 있는지 다시 판단합니다.

이렇게 보면 원문, 검토한 지식, 검색 결과는 서로 다른 역할을 가집니다. 원문은 맥락과 출처를 제공하고, 검토한 지식은 어떤 조건에서 다시 사용할 수 있는지를 설명하며, 검색 결과는 현재 질문과 관련된 후보를 찾아줍니다. 검색은 발견을 돕지만 채택을 대신하지 않습니다.

예를 들어 제품의 색을 찾았다고 해도 초기 시안인지 이번 소개용 버전인지 확인하지 않으면 잘못된 장면을 만들 수 있습니다. 우리는 결과에 어떤 자료를 실제로 채택했는지도 연결해 둡니다. 그래야 나중에 검색 순서가 달라져도 당시 무엇을 믿었는지 다시 설명할 수 있습니다.

정보가 충돌하거나 다시 필요할 때 무엇을 비교하는가

최신이라는 한 가지 기준보다 현재 문제에 맞는 적용 가능성을 비교해야 합니다.

새 자료가 나왔다고 해서 이전 자료가 곧바로 틀린 것은 아닙니다. 같은 제품라도 초기 시안과 이번 소개용 버전의 색이 다르다면 두 정보는 대상이 달라 모두 맞을 수 있습니다. 우리는 먼저 무엇을 설명하는 자료인지, 언제 관측됐는지, 어떤 목적에 쓰려는지를 비교합니다.

충돌을 풀 때는 최신성뿐 아니라 출처, 대상 범위, 변경 시점, 사용 목적을 함께 봅니다. 최신 자료가 다른 제품 버전을 설명한다면 현재 작업에는 이전 자료가 더 적합할 수도 있습니다. 반대로 같은 대상의 조건이 바뀐 것이라면 새 근거를 채택하되 무엇이 달라졌는지 추적할 수 있게 남깁니다.

재사용에서도 같은 기준이 필요합니다. 검색으로 비슷한 항목을 다시 찾았더라도 당시 채택했던 근거와 같은 것인지 확인해야 합니다. ‘무엇을 찾았는가’보다 ‘무엇을 실제 판단에 사용했는가’를 남기는 이유가 여기에 있습니다.

오래된 근거를 어떻게 판단에서 빼고 다시 사용할 것인가

더 이상 현재 판단에 쓰지 않는 근거와 존재하지 않는 근거를 구분해야 과거의 이유를 보존할 수 있습니다.

제품 조건이 바뀌어 이전 설명을 더 이상 사용하면 안 되는 경우가 있습니다. 이때 오래된 자료를 모두 삭제하면 과거 결과가 왜 그렇게 만들어졌는지도 함께 사라질 수 있습니다. 우리는 현재 재사용 대상에서 제외하는 것과 과거 판단의 근거를 보존하는 것을 구분합니다.

이 구분은 ‘지금도 쓸 수 있는가’와 ‘과거에 사용됐는가’가 다른 질문이기 때문에 필요합니다. 새 검색에서는 오래된 근거를 제외하면서도, 과거 산출물에서는 당시 어떤 정보가 선택됐는지 찾을 수 있어야 합니다. 그래야 변경 전후의 영향도 설명할 수 있습니다.

지식 관리의 목적은 모든 정보를 영원히 활성 상태로 쌓아 두는 데 있지 않습니다. 현재 판단에 적합한 근거를 선별하고, 바뀐 근거는 새 판단에서 빠지게 하면서, 필요할 때 과거의 맥락을 되짚을 수 있게 만드는 것이 핵심입니다.
