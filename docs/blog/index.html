요청을 작업으로 바꾸는 과정

에이전트에게 일을 맡길 때 출발점은 모델이나 도구가 아니라 무엇을 끝내야 하는가입니다.

3개 주제 ↗02

작업 상태와 다음 행동 관리하기

4개 주제 ↗03

작업에서 얻은 정보를 다시 쓰는 방법

에이전트가 많은 문서를 가지고 있다고 해서 항상 더 좋은 판단을 하는 것은 아닙니다.

4개 주제 ↗04

필요한 모델과 워크플로우 고르기

4개 주제 ↗05

이미지 의도와 결과를 함께 확인하기

이미지 생성에서는 프롬프트를 잘 쓰는 것만으로 작업이 끝나지 않습니다.

4개 주제 ↗06

영상의 장면과 타임라인 관리하기
