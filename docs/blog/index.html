01

한 요청이 다섯 분야를 지나 완성되기까지

하나의 요청이 판단·선택·생성·검수를 거쳐 설명 가능한 결과가 되는 전체 흐름을 살펴봅니다.

3개 주제 ↗02

작업 — 진행을 따라가고 계속할 수 있게 두기

작업이 어느 지점에 있는지, 다음에 무엇을 해도 되는지, 바뀐 뒤에도 안전하게 이어가는지를 분리해 관리하는 이유를 설명합니다.

4개 주제 ↗03

지식 — 어떤 것을 믿고 판단할지를 고르는 일

자료를 많이 모은다고 판단이 좋아지지 않습니다. 출처·적용 범위·상태를 확인해 현재 판단에 쓸 근거를 고르는 일을 설명합니다.

4개 주제 ↗04

재료 — 어떤 것을 쓸지를 조건과 함께 고르는 일

실행 자원을 이름만으로 고르지 않습니다. 버전·환경·호환 조건까지 함께 확인해야 결과를 재현하고, 바뀐 것을 설명할 수 있는 이유를 다룹니다.

4개 주제 ↗05

이미지 — 문장을 화면으로 옮기고 확인하기

말로 표현한 의도를 화면의 구성과 실행 조건으로 바꾸고, 만들어진 파일과 시각적 목적을 서로 다른 기준으로 확인하는 과정을 설명합니다.

4개 주제 ↗06

영상 — 장면을 이어 하나의 흐름으로 확인하기

각 장면의 목적과 시간을 연결해 하나의 흐름을 만들고, 일부만 고쳤더라도 실제 완성 영상의 전체를 다시 확인해야 하는 이유를 설명합니다.

4개 주제 ↗07

통합 — 결과를 근거까지 따라가기

요청에서 근거·선택·산출물·검수로 이어진 판단을 결과에서 거슬러 따라가고, 잘 된 것과 어긋난 것을 비교해 다른 일에도 쓰는 원리를 정리합니다.
