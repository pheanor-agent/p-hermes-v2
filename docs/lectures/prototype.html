05 / 데이터 계약 제안 · 순수 데이터 예제

조건을 쓰는 일과,
통과를 증명하는 일은 다릅니다.

카탈로그 선택을 합성 데이터로 표현합니다. 아래 값은 운영 자원과 연결되지 않습니다.

JSON / 합성 입력
{
  "selected_count": 1,
  "template_id": "sample-template",
  "variant_id": "sample-variant",
  "release_id": "sample-release"
}
합성 예제 · CPU 검사 PASS

작은 계약부터
직접 확인합니다.

선택 수 1, 필수 식별자 확인.
잘못된 선택 수와 빈 식별자는
거부되는 것을 검사했습니다.

화면의 JSON을 실제 검사했습니다. 운영 시스템·미디어 생성 성공의 증거는 아닙니다.

근거 읽는 법 관측 = 소스를 읽어 확인 · 제안 = 새 설계 · 실행 입증 = 실행 증거 필요. 이 강의의 도식과 계약은 제안이며 운영 동작의 입증이 아닙니다.
