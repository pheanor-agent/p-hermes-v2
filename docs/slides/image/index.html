설명

파라미터는 실행에 전달하는 설정값입니다. 비교에서 무엇을 바꾸고 무엇을 고정할지 정해야 차이를 해석하기 쉽습니다.

공개 함수는 width와 height를 64부터 8192 사이의 8의 배수 정수로 받습니다. seed는 0 이상 63비트 범위 정수입니다. 1281이라는 너비는 실제 검사에서 거부됩니다.
