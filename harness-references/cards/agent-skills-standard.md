# Agent Skills standard

- 원문: https://agentskills.io/home
- 규격: https://agentskills.io/specification
- 출처 시점: 규격 홈페이지; 직접 확인 2026-10-14. 사용자 제공 링크 확인 2026-06-02 (KST).
- 주제: skills/tools · context/knowledge
- 상태: 사용자 제공; 현재 knowledge reference 카드 등록은 확인되지 않음. 형식 참고이며 개별 skill의 품질·안전 보증 아님.
- 권리: 표준/사이트의 별도 조건 미확인. 요약·링크만; 전문 미보존.

## 자체 요약

Agent Skills는 에이전트가 절차적 능력과 도메인 지식을 발견·로드할 수 있도록 디렉터리와 `SKILL.md` 중심으로 구성하는 portable format을 표방한다. 규격 본문과 구현별 지원 범위를 원문에서 구분해 확인해야 한다.

## Hermes 관련성

작업별 절차를 짧은 metadata와 필요 시 읽는 상세 자료로 나누는 discoverability를 비교하는 기준이다. Hermes의 skill 로더·runtime 호환성은 Hermes 자체 공식 문서로 검증해야 합니다.
