# 유지보수 및 업데이트

1. 새 후보는 원천 URL/제공 시점/등록 여부/실제 사용 증거/권리를 각각 확인하고, 미확인은 `null` 또는 `unknown`으로 남깁니다.
2. 기존 카드와 canonical URL을 먼저 대조해 URL 중복을 제거합니다. 번역/HTML/abstract URL은 같은 작품이면 alternate URL로 그룹화하고, 독립 산출물은 별도 카드로 둡니다.
3. 원문을 통째로 복사하지 않습니다. 라이선스가 불명확하면 링크와 자체 요약만 남기며, 비공개 첨부는 출처 확인 등급만 기록합니다.
4. 카드를 추가/수정한 뒤 `manifest.json`의 레코드와 카운트를 갱신하고, 같은 레코드 순서로 `manifest.csv`를 다시 내보냅니다. `CATALOG.md`의 모든 관련 주제 목차 및 `README.md` 읽기 순서/주제 포인터를 갱신합니다.
5. 검사: JSON parse, JSON/CSV 행 수 대조, 각 카드 경로 존재, 각 manifest 레코드당 고유 canonical URL, 중복 URL/카드, 로컬 절대경로·비공개 식별자 검색을 수행합니다.
6. 출처 또는 이용 상태가 바뀌면 갱신일을 올리고 근거 수준/한계를 명시합니다. 이전 제공 증거를 최신성 검증으로 오인하지 않습니다.
