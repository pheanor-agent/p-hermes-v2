# Six-course lecture release

Status: implementation in progress. This checklist records the requested end state; unchecked work is not a delivered feature.

- [ ] Six complete HTML courses: overview, tasks, knowledge, catalog, image, video.
- [ ] All 72 planned learning scenes covered with defined keywords, concrete mechanisms, meaningful visuals, audience prompts and transitions.
- [ ] Full presenter notes: explanation, answer, hold points, scene timing, technical sources and next-scene bridge.
- [x] Six representative designs built and visually reviewed before extending the full courses.
- [ ] All planned A01–A13 graphic/media roles fulfilled with real evidence or clearly identified educational assets.
- [ ] Actual media: consistent image comparisons, 12-second A/B edits from the same shots, boundary-frame comparison, and an independently verified real video file.
- [ ] Real public implementation examples and failure results, including CAS, approval invalidation, rollback, knowledge retirement, pin/digest/binding failures and changed image references.
- [ ] Public implementation and operational architecture scopes clearly distinguished.
- [ ] Six audience PDFs rendered and inspected; final fragment evidence preserved and speaker answers excluded.
- [ ] Separate speaker view, keyboard navigation, full screen, direct scene links and reduced motion checked.
- [ ] Offline package opens without network; media and speaker view verified.
- [ ] Wiki, blog, home, course directory, examples, design sources and licenses updated consistently.
- [ ] Screens inspected at 1280×720 and 1920×1080; all slides checked for overflow, missing glyphs/assets and poor emphasis.
- [ ] Consecutive teaching sequences rehearsed for timing and flow; visible issues corrected and rechecked.
- [ ] Versioned changes pushed to GitHub; CI, Pages deployment and live public content verified at the final commit.

Automatic tests establish only the properties they inspect. Static art boards, generated diagrams and green builds do not establish lecture completion, media fidelity or learner engagement.
